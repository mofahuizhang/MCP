# MCP 控制层协议规范

模块互连与控制的协议规范。2026-10-20 定稿，副题「律令格式」。

> 一句话：MCP 是模块互连与控制的协议底座，以 C₁–C₄ 四层语义回答内容如何编码、消息如何传递、语境如何保持、控制如何实施。

## 讲什么

体例取律令格式：律·根本规则、令·制度安排、格·补充规定、式·操作细则，四卷之后附原理与依据、疏议·立法说明、适用与不适用。

核心是四层语义封存：C₁ Content（拼装什么、内容如何编码）／C₂ Message（消息如何传递）／C₃ Context（语境如何保持）／C₄ Control（允许什么、调节多少、传不动时如何处置）。编号封存，不设第五层。

C₁–C₃ 与行业 MCP 既有分层同构，本书的增量在 **C₄ 控制层**——OSI 七层里没有与之对应的层。另需说明：两套分层同构而不等同，OSI 管比特如何到达，C₁–C₄ 管含义如何互认，可并置参照，不宜互相替代。

## 名字

书名作《MCP 控制层协议规范》，不径称《MCP 协议规范》。

一为避与行业标准同名：本书复用行业 MCP 下两层，增量在 C₄，加「控制层」三字见其界限。
二为登记标题须短：全名 11 个非特殊字符，在 36 字上限之内。

正文中「MCP」仍指这套协议底座，不改。

## 与他三件的关系

| 简称 | 书名 | 关系 |
|---|---|---|
| 《架构》 | 内核旋钮架构 | 单主体内部怎么搭，本书不论 |
| 《主篇》 | 拼好模主篇 | 多主体怎么治，本书不论 |
| 《园丁》 | 园丁计划 | 系统怎么随时间演化，本书不论 |

本书只声明交互接口；下游只引本书编号（如「格 4」「式 3」），不复制本书定义。
